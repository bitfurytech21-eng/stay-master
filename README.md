# stay-master

A static rebuild of the [stay-master.com](https://www.stay-master.com) website — 23 pages covering the homepage, 9 city pages and 13 building detail pages.

No build step, no framework, no dependencies to install. Open `index.html` in a browser, or serve the folder with any static file server.

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

## How it's built

The HTML is generated by `build.py` from `data/site.json`. To regenerate every page after editing content:

```bash
python3 build.py
```

`build.py` writes all 23 HTML files in place. The generated HTML is committed, so the site works without running the generator — you only need it if you change `data/site.json`.

## Maps

Every building page has a live [Leaflet](https://leafletjs.com) 1.9.4 map with OpenStreetMap raster tiles. Leaflet is vendored in `vendor/leaflet/` rather than loaded from a CDN, so the only third-party request a page makes is for map tiles from `tile.openstreetmap.org`.

Each building is pinned at coordinates geocoded from its real street address. Scroll-wheel zoom is disabled until the map is clicked or focused, so the page doesn't hijack scrolling. If Leaflet or the tiles fail to load, a fallback panel with a direct OpenStreetMap link is shown instead of an empty box.

Map data © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), available under the ODbL.

## Photo galleries

Building pages have a hero photo strip and a full gallery grid. Both open the same lightbox, which supports prev/next, arrow keys, Escape, a photo counter and focus trapping.

## Accessibility

- Skip link on every page
- Semantic landmarks and heading order
- ARIA labels on the menu, maps and gallery controls
- Full keyboard navigation, including the lightbox and map panning
- `prefers-reduced-motion` fallback for transitions
- Colour contrast checked on the dark city section

## What this is not

This is a **static front-end rebuild**. It has real content, real photography, real maps, working navigation and galleries — but:

- The booking buttons link out to master's actual reservation system (`*.reserve-online.net`). Nothing on this site takes a booking.
- There is no backend, no database, no form submission, no email sending and no analytics.
- The language switcher in the menu is present but not wired to translations.
